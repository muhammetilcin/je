# JE — Jeolojik-Jeoteknik Saha Takip

İlk prototip.

## Bu sürümde
- Yönetici / Firma demo rolü
- Çoklu iş listesi
- Kısa iş adı + hektar + firma + durum
- KML/KMZ çalışma alanı içe aktarma
- KML/KMZ sondaj noktaları içe aktarma
- Leaflet + OpenStreetMap harita
- Yerel tarayıcı depolaması (localStorage)

## Sonraki aşama
- Supabase Auth
- Firma bazlı RLS
- PostgreSQL/PostGIS veri modeli
- Fotoğraf ve PDF depolama
- Sondaj / SPT / numune / YASS saha formları
- Ofis kontrol notları
- Canlı ilerleme paneli

> Not: Bu prototipte veriler yalnızca kullanılan tarayıcıda tutulur. Gerçek ortak veri paylaşımı için Supabase bağlantısı sonraki aşamada eklenecek.
